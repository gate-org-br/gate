<g-context-menu>

The <g-context-menu> is a custom element that replaces the browser’s default context menu, handling positioning, closing, and submenu support. You can open it programmatically with GContextMenu.show(context, x, y, ...actions), where each action is an object with properties such as icon, title, text, and action. The action can be a link (string), a function, an array for a static submenu, or an object with type (module or source) and value (path or URL) to load a dynamic submenu via fetch or import. Menus can also be triggered automatically using the data-contextmenu:source or data-contextmenu:module attributes in HTML. Submenus open with a short delay to prevent accidental activation and close automatically when the mouse leaves or on outside clicks.
