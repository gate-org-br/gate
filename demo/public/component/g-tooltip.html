<g-tooltip>

The <g-tooltip> component provides a seamless way to attach tooltips to elements within your HTML structure.

The <g-tooltip> allows you to precisely control its display position. By utilizing the optional position attribute, you can indicate the preferred location for the tooltip concerning its parent element. The engine will make every effort to display the tooltip at the specified position; however, if it's not feasible due to space constraints or other factors, the engine intelligently selects an alternative position for optimal visibility. This versatility ensures a seamless integration of tooltips while accommodating dynamic layout scenarios.

The data-tooltip attribute references a selector of an existing <g-tooltip> element in the DOM. The tooltip will display the content found inside the referenced element, allowing you to reuse and centralize tooltip definitions.

The data-tooltip-source attribute defines a URL to fetch tooltip content dynamically. If the server responds with JSON, the engine automatically converts it into HTML before rendering, making it possible to build expressive tooltips from structured data.

The data-tooltip-text attribute provides plain text that will be shown directly inside the tooltip. This is the simplest option for quick, inline tooltips without needing additional markup or external sources.

The optional data-tooltip:position attribute can also be used in any of these cases to specify the preferred positioning of the tooltip relative to its target element.
