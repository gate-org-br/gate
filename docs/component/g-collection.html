<g-collection>

The <g-collection> custom element manages repeated form groups. Its light DOM <template> is used as a live template for new items, while the rendered items stay inside the component shadow DOM.

The value property is a form string made of Base64 encoded JSON entries separated by semicolons. The entries property exposes the same data as an array for JavaScript usage.

Form

This example shows placeholder text, a localized add button label, and validation with required and min.

API

This example uses entries for JavaScript data and value for the serialized form value.

Template

New items clone the current light DOM template. Changing the template content changes the template used by the next items without changing existing ones.
