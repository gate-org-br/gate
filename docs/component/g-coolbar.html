<g-coolbar>

The <g-coolbar> component displays actions in a horizontal toolbar using links, buttons and .g-command elements. It supports semantic button variants, greedy spacing with <hr>, reversed alignment with reverse, and an automatic overflow menu when the available width is not enough to display all actions at once.

Example 1

By default, toolbar actions are aligned from right to left.

Example 2

The reverse attribute changes the alignment to left-to-right.
