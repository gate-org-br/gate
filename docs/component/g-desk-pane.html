<g-desk-pane>

The <g-desk-pane> component displays a grid of commands using links, buttons and nested panes. Each item is shown as a large visual tile with text plus an icon or image, making it useful for desktop-style menus, shortcuts and grouped navigation. Nested <g-desk-pane> elements behave like submenus inside the same layout.

Example 1

The default layout places the icon above the text, creating a square tile for each command. This is the most visual presentation and works well for dashboards and command launchers.
