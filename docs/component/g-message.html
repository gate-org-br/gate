<g-message>

The g-message component is a compact message box for short status information, tips, warnings and errors. It is designed to be scanned quickly and may optionally display an icon. Use g-message for operational guidance or feedback near the current context. Common combinations use semantic variant classes such as success, warning, error and question, together with fill and icon. For longer conceptual explanations or highlighted content blocks, prefer g-callout.
