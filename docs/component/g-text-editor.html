<g-text-editor>

The <g-text-editor> component is a practical rich text editor for forms. It keeps HTML as its value, integrates with form submission through the form-associated custom elements API, and provides the editing features that are commonly needed in business applications without requiring a large editor stack. It supports common inline formatting, undo and redo, embedded attachments pasted from the clipboard, and validation through attributes such as required, maxlength and pattern. In practice it behaves like an expanded <textarea> whose value is the generated HTML content. The goal is to keep the component simple to use as a field, without requiring the application to adopt a large JavaScript editor model. Use it when you need a lightweight editor that fits naturally into the rest of the form model; if the application only needs plain text, a normal <textarea> is still the simpler choice.
