Gate

Gate is a full stack application framework that combines screen routing, authentication, authorization, SQL access, HTML targets and web components in a single model. The goal is to keep application structure close to the code: packages define modules, screen classes define routes and call methods define actions.

This documentation is organized by the main parts of the framework. Start with Routing if you want to understand how screens are discovered and how URLs map to Java classes and methods. Go to Authentication and Access Control to understand how Gate identifies users and protects routes. The Targets and Components sections document the browser-side model, while SQL covers the database API used by applications built on Gate.

If you are new to Gate, the recommended reading order is Routing, Authentication, Access Control and then SQL. After that, read Targets and Components according to the type of screen you are building.
