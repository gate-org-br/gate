Delete

Use Delete when the removal must stay explicit and auditable. In most cases, that means a clear predicate and an explicit row-count check.

Delete By ID

The most common delete flow is a simple, scoped delete by identifier.

Delete.from("Attachment")
	.where(Condition.of("id").eq(value.getId()))
	.build()
	.connect(linkSource.get())
	.execute();
Not Found Guard

If the record must exist, validate the affected row count.

if (Delete.from("Organization")
	.where(Condition.of("id").eq(value.getId()))
	.build()
	.connect(linkSource.get())
	.execute() == 0)
	throw new NotFoundException();
Delete With Subquery

Use a subquery when the delete target depends on another relational lookup. 

Delete.from("Attachment")
	.where(Condition.of("Attachment.id")
		.isEq(Select.expression("Category.Attachment$id")
			.from("Category")
			.where(Condition.of("Category.id").eq(category.getId()))))
	.build()
	.connect(linkSource.get())
	.execute();
Main Methods
Method Use it for
from(...) Choose the table to delete from
where(...) Restrict which rows will be deleted
build() Produce the executable delete
execute() Run the delete and return the affected row count
