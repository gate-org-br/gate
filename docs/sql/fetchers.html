Fetchers

After a query is connected to a Link, choose the fetch method by the shape of data you want back. This is usually the last decision in the DAO method.

Choosing The Result Shape
If you need Use
A single scalar value fetchObject(...) or fetchInt(), fetchBoolean(), etc.
A list of first-column values fetchObjectList(...) or fetchObjectSet(...)
A single entity fetchEntity(...)
A list or set of entities fetchEntityList(...) or fetchEntitySet(...)
A flexible row structure fetchMap(), fetchMapList(), fetchMapPage()
Analytical output fetchDataGrid() or fetchPivotTable(...)
JSON directly fetchJsonObject(), fetchJsonArray(), fetchJsonTree()
Custom cursor handling fetch(fetcher) or stream(mapper)
Common Examples 
Optional<Integer> total = query.fetchObject(Integer.class);

List<String> names = query.fetchObjectList(String.class);

Optional<User> user = query.fetchEntity(User.class);

List<User> users = query.fetchEntityList(User.class);

List<Map<String, Object>> rows = query.fetchMapList();

Page<Map<String, Object>> page = query.fetchMapPage(20, 0);

JsonArray json = query.fetchJsonArray();
Main Methods
Method Use it for
fetchObject(...) Read one value from the first column of the first row
fetchObjectList(...), fetchObjectSet(...) Read many first-column values
fetchEntity(...) Materialize one object
fetchEntityList(...), fetchEntitySet(...) Materialize many objects
fetchEntityPage(...) Materialize a page of entities
fetchMap(...), fetchMapList() Return rows as maps keyed by column name
fetchMapPage(...) Return a page of map rows
fetchDataGrid(...) Read analytical tables and report-style outputs
fetchJsonObject(), fetchJsonArray() Return JSON directly from the query result
fetch(fetcher), stream(mapper) Take full control of cursor traversal or result mapping
