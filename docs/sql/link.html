Link

Link is the entry point for execution. It owns the JDBC connection, controls the transaction, and creates executable queries and commands.

Basic Read

Use from(...) when you want to execute a query.

try (Link link = Link.of("datasourcename"))
{
	Optional<Integer> total = link
		.from("select count(*) from Person where name like ?")
		.parameters("A%")
		.fetchObject(Integer.class);
}
SQL From Resource

For long queries, keep SQL in a resource file and load it through from(...) or prepare(...). 

try (Link link = Link.of("datasourcename"))
{
	List<User> users = link
		.from(getClass().getResource("UserDao/search(User).sql"))
		.parameters(active, name)
		.fetchEntityList(User.class);
}
Command Execution

Use prepare(...) for commands such as insert, update, and delete.

try (Link link = Link.of("datasourcename"))
{
	int rows = link
		.prepare("update User set active = ? where id = ?")
		.parameters(true, userId)
		.execute();
}
Transaction

Start the transaction explicitly. If the Link is closed before a commit(), it rolls back automatically. 


try (Link link = Link.of("datasourcename"))
{
	link.beginTran();
		link.prepare("insert into Audit (message) values (?)")
			.parameters("created person")
			.execute();
	link.commit();
}
Main Methods
Method Use it for
of(...) Open a link from a datasource name, datasource, or JDBC connection
from(...) Create an executable query from SQL text, a resource, or a built query
prepare(...) Create an executable command from SQL text, a resource, or a built write statement
createCommand(...) Access the lower-level command API directly
beginTran() Start an explicit transaction
commit() Persist the transaction changes
rollback() Cancel the transaction changes
close() Close the connection; if a transaction is still open, it is rolled back
