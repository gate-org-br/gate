gate.sql

gate.sql is a SQL-first API. You write SQL, compose the dynamic parts in Java, execute through Link, and choose how the result should be fetched.

Quick Start

A typical read flow has four steps:

  1. Start from a SQL resource file or a builder
  2. Add dynamic filters with Condition
  3. Connect the query with Link
  4. Fetch the result in the shape you need
List<User> users = Select
	.of(getClass().getResource("UserDao/search(User).sql"))
	.where(Condition.TRUE
		.and("User.name").lk(filter.getName())
		.and("User.active").eq(filter.getActive()))
	.orderBy("User.name")
	.build()
	.connect(getLink())
	.fetchEntityList(User.class);
Write Flow

Write operations follow the same idea: build the SQL, connect it, execute it, and handle the result explicitly. 

if (Update.table("Organization")
	.set("name", value.getName())
	.set("host", value.getHost())
	.where(Condition.of("id").eq(value.getId()))
	.build()
	.connect(getLink())
	.execute() == 0)
