Production Patterns

This page focuses on combinations that usually age well in DAO code: readable SQL, explicit write scope, and predictable result handling.

Resource SQL + Java Filters

Keep the base SQL in a resource file and assemble only the dynamic pieces in Java. 

var condition = Condition.TRUE
	.and("User.name").lk(filter.getName())
	.and("User.username").eq(filter.getUsername())
	.and().when(!getUser().isSuperUser()).expression("Access.id").isNotNull();

List<User> users = Select
	.of(getClass().getResource("UserDao/search(User).sql"))
	.where(condition)
	.orderBy("User.name")
	.build()
	.connect(linkSource.get())
	.fetchEntityList(User.class);
EXISTS For Access Rules

When the access rule is relational, keep it in SQL with exists. 

Condition access = Condition
	.of("Ticket.confidential").isEq("false")
	.or("Ticket.requesterId").eq(getUser().getId())
	.or().exists(Select.expression("id")
		.from("Share")
		.where(Condition.of("Share.Ticket$id").isEq("Ticket.id")
			.and("Share.User$id").eq(getUser().getId())));
Write Guard

If an update or delete is supposed to hit one existing row, treat zero affected rows as a failure. 

if (Delete.from("Organization")
	.where(Condition.of("id").eq(value.getId()))
	.build()
	.connect(linkSource.get())
	.execute() == 0)
	throw new NotFoundException();
Generated Keys

Use generated key helpers immediately after inserts so the caller leaves the DAO with the final identifier already attached. 

Insert.into("Organization")
	.set("name", value.getName())
	.build()
	.connect(linkSource.get())
	.fetchGeneratedKey(ID.class)
	.ifPresent(value::setId);
Checklist
Guideline Why it helps
Keep long SQL in resource files Readability improves without losing SQL control
Use Condition.TRUE as the default baseline Optional filters stay easy to compose
Prefer exists for relational visibility rules The filtering stays in the database
Check affected rows on required updates and deletes No silent write failures
Attach generated keys immediately after inserts The object leaves the DAO complete
