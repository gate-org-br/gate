Select

Use Select to build read queries. In most codebases, the common pattern is: keep the base SQL readable, add the dynamic parts in Java, then fetch the result in the shape the caller needs.

Recommended Style

The most practical style is SQL in a resource file plus dynamic filtering in Java. 

List<Map<String, Object>> rows = Select
	.of(getClass().getResource("CallDao/search(Call).sql"))
	.where(getCondition(filter))
	.orderBy("Call.createdAt desc")
	.build()
	.connect(getLink())
	.fetchMapList();
Inline Builder

For shorter queries, build the whole select in Java.

List<User> users = Select
	.expression("User.id").as("id")
	.expression("User.name").as("name")
	.from("User")
	.where(Condition.of("User.active").eq(true))
	.orderBy("User.name")
	.build()
	.connect(getLink())
	.fetchEntityList(User.class);
Join and Condition

Join clauses and filters normally use Condition. Use isEq(...) when comparing one field with another field. 

List<User> users = Select
	.expression("UserAccount.id").as("id")
	.expression("User.name").as("name")
	.from("UserAccount")
	.join("User").on(Condition.of("UserAccount.id").isEq("User.id"))
	.where(Condition.of("UserAccount.active").eq(true))
	.build()
	.connect(getLink())
	.fetchEntityList(User.class);
Property References

When a selected field belongs to a mapped Java type, you can reference it directly from the model instead of writing the column name by hand. 

List<User> users = Select
	.expression(User::getId).as("id")
	.expression(User::getName).as("name")
	.from("User")
	.where(Condition.of(User::getActive).eq(true))
	.orderBy("name")
	.build()
	.connect(getLink())
	.fetchEntityList(User.class);
Grouping and Pagination

Use the builder methods directly for grouping, ordering, and pagination. The result can still be fetched as maps, entities, grids, or pages. 

Page<Map<String, Object>> page = Select
	.of(getClass().getResource("CallDao/search(Call).sql"))
	.where(getCondition(filter))
	.sort(order)
	.paginate(pageSize, pageIndx)
	.build()
	.connect(getLink())
	.fetchMapPage(pageSize, pageIndx);
Main Methods
Method Use it for
of(...) Start from a SQL resource file or existing SQL text
expression(...) Add selected columns or expressions, including property references
from(...) Define the base table or subquery source
join(...), leftJoin(...) Add joins
where(...) Attach a condition built with Condition, including property-reference predicates
groupBy(...) Group rows for aggregate queries
having(...) Filter grouped rows
orderBy(...) Apply a fixed ordering
sort(...) Apply a runtime ordering string
paginate(...) Apply page size and page index
build() Produce the executable query object
connect(link) Attach the query to a Link for execution
