@dataset

The @dataset target extracts data from a <table> element and pass it to the pipeline. The table selector must be passed on the target parameter list.

Example 1 さ

On this example, the @dataset target extracts data from the popularity <table> and pass it to the @value target. The @value target sets the value property of the <g-chart> element to be the data extracted from the table. This pattern facilitates the automatic generation of charts from tabular data.
