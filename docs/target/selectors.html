Selectors

Many Gate targets accept a selector parameter. In the simple case, this parameter is just a normal CSS selector such as #content. Gate also supports a navigation syntax for cases where the target element should be found relative to the trigger element.

A selector can start with this to indicate navigation relative to the trigger element or be a valid CSS selector to directly target an element on the document. Selectors can be quoted with double (") or single (') quotes. Steps can be separated by dots (.) or enclosed with square brackets ([]).

This page describes the advanced selector language. If you are starting with Gate, you will usually only need a normal CSS selector such as #content.

this
Skips the current step and continues to the next one.
parent()
Navigates to the parent of the element.
parent(number)
Navigates to the nth parent of the element.
parent(selector)
Navigates to the first parent of the element that matches the provided CSS selector.
prev()
Navigates to the previous sibling of the element.
prev(number)
Navigates to the nth previous sibling of the element.
prev(selector)
Navigates to the first previous sibling of the element that matches the provided CSS selector.
next()
Navigates to the next sibling of the element.
next(number)
Navigates to the nth next sibling of the element.
next(selector)
Navigates to the first next sibling of the element that matches the provided CSS selector.
search(selector)
Navigates to the first child element that matches the provided CSS selector.
[+number]
Navigates to the nth child element of the current source element.
[-number]
Navigates to the nth child element of the current source element in reverse order.
[selector]
Navigates to the first direct child element that matches the provided CSS selector.

The following examples show both the simple and the relative forms.

#content
Selects the element with id content.
section
Selects the first matching section element in the document.
this.parent(section)
Navigates to the first parent section element of the trigger element.
this.parent(2).next('.class-name')
Navigates to the sibling with class class-name of the third parent of the trigger element.
this.prev(-1)[3]
Navigates to the fourth child of the previous sibling of the trigger element.
