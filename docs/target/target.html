Getting Started

A target tells the browser what to do with the result of a request. HTML already provides the standard navigation targets such as _self, _blank, _top and _parent. Gate adds more targets, identified by the @ prefix, to support common interface behaviors such as replacing HTML, opening dialogs, showing messages and stacking content.

The most common case is simple: an element triggers a request and a Gate target decides how the result should be applied to the interface. For example, @inner-html(#content) means: execute the request and replace the contents of #content with the returned HTML.

You do not need to learn all target types to start using Gate. A very common first step is just: 

<a href="/page" target="@inner-html(#content)">Open</a>
<div id="content"></div>

Trigger Attributes

Every trigger defines three concepts: action, which is the URL to be called; method, which is the HTTP method of the request; and target, which tells Gate what should be done with the result of that request.

Gate reuses the native HTML attributes whenever the element already has a standard way to define request data. When the element does not have one, Gate uses data-* attributes.

Concept Anchor Form Button Other elements
Action href action formaction data-action
Method implicit GET or data-method method formmethod data-method
Target target target formtarget data-target

Basic Selectors

Many Gate targets accept a selector parameter. For most applications, the usual case is a normal CSS selector such as #content, #dialog or main section.

If you are starting with Gate, you can usually think of the selector parameter as "the CSS selector of the element that will receive the result".

Examples:

  • @inner-html(#content)
  • @outer-html(#summary)
  • @value(#username)

Gate also supports an advanced selector navigation syntax based on the trigger element, using expressions such as this.parent().next(). That syntax is documented separately because it is more advanced than the basic CSS selector case.

See Selectors for the advanced selector language.
