Complete Fetchers

This page documents all built-in methods from Fetchable. Examples are grouped by output shape and include practical guidance from real DAO usage.

Base

Use base methods when default helpers are not enough.

  • <T> T fetch(Fetcher<T> fetcher)
  • <T> Stream<T> stream(Mapper<T> mapper)
 
List<Group> grouped = query.fetch(cursor -> {
	// custom cursor traversal
	return result;
});

Stream<Person> stream = query.stream(new EntityMapper<>(Person.class));
Object

First-column focused fetchers for scalar and light lookup flows.

  • objectStream(), objectStream(Class<T>)
  • fetchObject(), fetchObject(Class<T>)
  • fetchObjectList(), fetchObjectSet()
  • fetchObjectList(Class<T>), fetchObjectSet(Class<T>)
 
Optional<Integer> total = query.fetchObject(Integer.class);
List<String> names = query.fetchObjectList(String.class);
Set<ID> ids = query.fetchObjectSet(ID.class);
Array

Array-shaped result consumption, typed or untyped.

  • fetchArray(), fetchIntArray()
  • arrayStream(), arrayStream(Class<?>...)
  • fetchArray(Class<?>...)
  • fetchArrayList(), fetchArraySet()
  • fetchArrayList(Class<?>...), fetchArraySet(Class<?>...)
 
Optional<Object[]> row = query.fetchArray(Integer.class, String.class);
List<Object[]> rows = query.fetchArrayList();
Optional<int[]> counters = query.fetchIntArray();
Map

Map-shaped output is very common for flexible search/list endpoints.

  • mapStream(), mapStream(Class[] types)
  • fetchMap(), fetchMap(Class<?>...)
  • fetchMapList(), fetchMapList(Class<?>...)
  • fetchMapPage(int pageSize, int pageIndx, Class<?>...)
 
List<Map<String, Object>> rows = query.fetchMapList(String.class, String.class, LocalDateTime.class);
Page<Map<String, Object>> page = query.fetchMapPage(20, 0, ID.class, String.class);
Entity

Most-used group in DAO codebases for domain object mapping.

  • entityStream(Class<T>)
  • fetchEntity(Class<T>)
  • fetchEntityList(Class<T>), fetchEntitySet(Class<T>)
  • fetchEntityPage(Class<T>, int pageSize, int pageIndx)
  • fetchEntityList(Class<T>, List<Property>), fetchEntitySet(Class<T>, List<Property>)
  • fetchEntityList(Class<T>, String... properties), fetchEntitySet(Class<T>, String... properties)
 
Optional<User> one = query.fetchEntity(User.class);
List<User> list = query.fetchEntityList(User.class);
Page<User> page = query.fetchEntityPage(User.class, 50, 0);
List<User> thin = query.fetchEntityList(User.class, "id", "name");
Grid and Pivot

Analytical outputs for dashboards and KPI screens.

  • fetchDataGrid(), fetchDataGrid(Class<?>...)
  • fetchPivotTable(Class<T>)
  • fetchPivotTable(Class<T>, T defaultValue)
 
DataGrid grid = query.fetchDataGrid(String.class, Integer.class, Percentage.class);
PivotTable<Double> pivot = query.fetchPivotTable(Double.class, 0.0);
JSON and ZIP

Output formats for APIs and export workflows.

  • fetchJsonObject()
  • fetchJsonArray()
  • fetchJsonTree()
  • fetchJsonDataset(), fetchJsonDataset(boolean includeHeader)
  • fetchZipPackage()
 
Optional<JsonObject> one = query.fetchJsonObject();
JsonArray rows = query.fetchJsonArray();
JsonArray tree = query.fetchJsonTree();
JsonArray dataset = query.fetchJsonDataset(true);
TempFile zip = query.fetchZipPackage();
Primitives

Scalar shortcuts for direct metric and existence flows.

  • fetchBoolean()
  • fetchChar()
  • fetchByte()
  • fetchShort()
  • fetchInt()
  • fetchLong()
  • fetchFloat()
  • fetchDouble()
 
boolean exists = query.fetchBoolean();
int total = query.fetchInt();
double avg = query.fetchDouble();
