GQN

GQN is a compact notation to define projection, filtering, and ordering from Java types. The package integrates GQN with Select, Insert, Update, Delete, and Link.select.

Select With Link 
Person person = link
	.select(Person.class)
	.properties("=id", "name")
	.parameters(ID.valueOf(1))
	.orElseThrow(NotFoundException::new);
Builders With GQN 
// query
Query q = Select.of(Person.class, "=id", "name", "?name=Maria");

// write
var insert = Insert.of(Person.class, "name", "birthdate");
var update = Update.of(Person.class, "=id", "name");
var delete = Delete.of(Person.class, "=id");
