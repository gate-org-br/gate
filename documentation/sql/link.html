Link

Link encapsulates the JDBC connection and execution/query operations. You can create it from a DataSource, a JNDI datasource name, or a direct JDBC connection.

Connection and Query 
try (Link link = new Link("datasourcename"))
{
	Optional<Integer> count = link
		.from("select count(*) from Person where name like ?")
		.parameters("A%")
		.fetchObject(Integer.class);
}
Transaction 
try (Link link = new Link("datasourcename"))
{
	link.beginTran();
	try
	{
		link.prepare("insert into Audit (message) values (?)")
			.parameters("created person")
			.execute();
		link.commit();
	}
	catch (Exception ex)
	{
		link.rollback();
		throw ex;
	}
}
SQL From Resource File 
try (Link link = new Link("datasourcename"))
{
	link.prepare(getClass().getResource("InsertPerson.sql"))
		.parameters(id, name, birthdate)
		.execute();
}
