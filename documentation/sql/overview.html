gate.sql

The gate.sql package provides a fluent API for SQL composition and execution, with practical support for dynamic filtering, transactional writes, and typed fetchers.

  • Link: connection, transaction, and command execution
  • Select + Condition: composable query and predicate builders
  • Insert, Update, Delete: write operations with generated key and affected-row patterns
  • Fetchable: typed output mapping for entities, maps, grids, JSON, and scalar values
